Do not hard-code the application to one AI provider.

- Replicate
- fal.ai
- Runway or another compatible video provider

Use environment variables for API keys.
NEVER expose API keys in frontend/client code.
All AI requests must go through secure backend/server routes.

If a provider/API key is not configured, show:
“AI provider is not configured. Please contact the administrator.”
Never pretend a generation succeeded.

GENERATION FLOW:
User selects tool
→ uploads image/video if required
→ enters prompt/settings
→ system checks credits
→ deduct credits only when generation is successfully submitted
→ call secure AI backend
→ track generation status:
pending / processing / completed / failed
→ save result
→ show preview
→ allow download
→ save to generation history.

If generation fails, refund the consumed credits automatically.
